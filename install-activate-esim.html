How to Install and Activate an eSIM Before Your Trip

The best time to install a travel eSIM is when you have reliable Wi-Fi and a few quiet minutes. That usually means before you leave home, at the airport, or at your hotel before a day out.

1. Confirm compatibility

Make sure your phone supports eSIM and is unlocked. Some carrier-locked devices cannot use another provider's eSIM even if the model supports the feature.

2. Add the eSIM profile

On iPhone, go to Settings, Cellular, then Add eSIM. On many Android phones, go to Network or Connections settings and add a SIM or mobile plan. Scan the QR code from your purchase email.

3. Label the line

Name the profile something clear, such as Travel Data or Europe eSIM. This makes it easier to choose the right line when switching mobile data.

4. Select it for mobile data

When you are ready to use the plan, set the eSIM as your data line. Keep your primary number for calls and messages if you need it, and follow the plan instructions for data roaming.

5. Test before relying on it

Open a map or website after activation. If data does not work, check the selected data line, roaming setting, and APN instructions from your plan provider.
